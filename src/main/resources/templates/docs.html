Dokumentacja aplikacji

Endpoint Metoda Opis Parametry
/menu GET Wyświetla menu aplikacji Brak
/students GET Wyświetla listę studentów Brak
/form GET Wyświetla formularz dodawania studenta Brak
/form POST Przesyła dane nowego studenta do bazy
  • firstName - Imię studenta
  • lastName - Nazwisko studenta
  • email - Email studenta
/search-page GET Wyświetla stronę wyszukiwania studenta po ID Brak
/search GET Wyszukuje studenta po ID
  • id - ID studenta
/delete POST Usuwa studenta po ID
  • id - ID studenta
/edit GET Wyświetla formularz edycji studenta
  • id - ID studenta
/update POST Aktualizuje dane studenta
  • id - ID studenta
  • firstName - Imię
  • lastName - Nazwisko
  • email - Email
